What is Graph Traversal?

Graph traversal is the process of systematically visiting the vertices of a graph. It is fundamental to Data Structures and Algorithms and is used in networking, path finding, AI, and more.

Queue · Level by level

Breadth-First Search

BFS explores a graph level by level, visiting nearby nodes before going deeper. Data structure: Queue (FIFO). Traversal: wide before deep. Common use: shortest path in unweighted graphs.

Stack · Depth first

Depth-First Search

DFS explores as far as possible along one path before backtracking. Data structure: Stack / recursion (LIFO). Traversal: deep before wide. Common use: path exploration and connectivity.

Neither algorithm is universally better — the right choice depends on the problem.

Complexity — BFS

Time O(V + E) · Space O(V)

Complexity — DFS

Time O(V + E) · Space O(V)

V = number of vertices, E = number of edges. Both visit every vertex and edge at most once.

BFS is used for

Shortest path (unweighted) · Network broadcasting · Social connections · Web crawling · Level-order exploration

DFS is used for

Maze solving · Cycle detection · Connected components · Topological sorting · Path exploration
